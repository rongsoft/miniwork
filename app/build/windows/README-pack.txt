Miniwork 0.1.4 · Windows 版（免安装，x64）
================================================

一、开始用
  双击 Miniwork.exe。
  首次运行 Windows 可能弹「Windows 已保护你的电脑」——这是未签名程序的
  常规提示，不是报错：点「更多信息」→「仍要运行」。

二、需要 WebView2 运行时
  Win10 / Win11 一般自带。如果提示缺少 WebView2 Runtime，装一次就行：
  https://developer.microsoft.com/microsoft-edge/webview2/

三、这一版最重要的一件事：不用再自己装浏览器
  browser\win64\ 里自带一份 Chromium（约 400MB），发布时会用它。
  请不要删这个目录——删了「扫码登录」就点不动了。

  上一版要用户自己装 Chrome 或 Edge，实际客户机上装没装完全不可控，
  于是「扫码登录」成了一个点了就报错的按钮。这一版把这份依赖包进来了。

四、数据和日志在哪
  都在同一个目录，把下面这行粘到资源管理器地址栏回车即可：

      %AppData%\miniwork

      miniwork.db     选题、稿子、发布台账（备份就复制这一个文件）
      config.json     数据源与模型配置
      miniwork.log    运行日志 —— 出问题先看这里

五、托盘和后台
  - 点右上角 ×：默认不退出，缩到右下角托盘，定时刷新照常跑
  - 左键点托盘图标：把窗口叫回来
  - 右键点托盘图标：打开主窗口 / 立即刷新 / 关窗后驻留托盘 / 退出 Miniwork
  - 设置页「后台运行」：关窗驻留、开机自启
  - 想彻底退出：托盘右键「退出 Miniwork」

六、再双击一次会怎样
  不会开出第二个窗口。第二份自己退出，并把已经开着的那个窗口叫到最前面。

七、自动发布（小红书 / 抖音 / 公众号）
  发布台 → 某个平台点「扫码登录」/「扫码绑定」。

  小红书、抖音
    平台页面会**并排显示在应用窗口右侧**，不是另开一个浏览器窗口。
    左边照常看选题和稿子，右边就是平台自己的网页：扫码、选择、发布都在里面。
    扫码一次，登录态存在 %AppData%\miniwork\publish\ 下，以后不用再扫。
    程序会自动上传图片/视频、填好标题正文标签，默认停在发布页不替你点
    「发布」——最后那一下由你按（面板上有开关可以改）。

  公众号
    这一版改成扫码绑定：扫码之后 AppID 自动填好。
    AppSecret 微信只显示一次，要你在后台点「重置」生成后复制过来
    ——这是唯一还需要你动手的一步，因为重置会让旧密钥立刻失效，
    机器替你点会把别的系统弄断。
    如果接口报 40164，就是本机出口 IP 不在白名单里，面板上会显示这个 IP。

八、已知情况
  - 未签名：SmartScreen 或杀软可能拦一次，属正常，放行即可
  - 只打了 x64；Windows on ARM 需要单独出一版（Chrome for Testing 没有 arm64 版）
  - 托盘图标会跟着系统主题切换

九、Mac 上已经配好的模型
  config.json 可以直接从 Mac 拷过来，路径：
      Mac  ~/Library/Application Support/miniwork/config.json
      Win  %AppData%\miniwork\config.json
